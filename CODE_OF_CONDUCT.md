# Code of Conduct

Kami adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, for every project space: issues, pull requests, discussions and any community channel.

In short: be respectful and constructive, assume good intent, and focus on what is best for the people using Kami. Harassment, personal attacks and publishing others' private information are not tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainers listed in [.github/CODEOWNERS](.github/CODEOWNERS), through GitHub's private channels (for example a private security advisory, marked as a conduct report). Reports are handled confidentially, and maintainers will follow the Contributor Covenant's enforcement guidelines.
