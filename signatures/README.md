# CLA signatures

The CLA bot writes `signatures/version1/cla.json` on the **`cla-signatures`** branch (not `dev` / `main`, which are protected).

Do not create or edit `cla.json` by hand. Contributors sign by commenting on the PR:

```text
I have read the CLA Document and I hereby sign the CLA
```

See [CLA.md](../CLA.md) and `.github/workflows/cla.yml`.
