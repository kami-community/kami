# LinkedIn distribution

## When to use
Founder-led posts and thoughtful comment targets.

## Access
Research/browser for public posts when available. **Manual copy/paste or composer deep link only** — no LinkedIn company-page API posting in MVP.

## Procedure
1. Draft a specific founder post tied to the campaign angle.
2. Optionally suggest 1–2 public posts worth a thoughtful comment.
3. Avoid engagement-bait templates.

## Output schema
platform=`linkedin` opportunity object.
