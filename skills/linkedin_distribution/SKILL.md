# LinkedIn distribution

## When to use
Founder-led posts and thoughtful comment targets.

## Access
Research/browser for public posts when available. **Manual copy/paste or composer deep link only** — no LinkedIn company-page API posting in MVP.

## Procedure
1. Follow `viral_formats` for current LinkedIn patterns; set `format_used` + `format_why`.
2. Draft a specific founder post tied to the campaign angle (no engagement-bait templates).
3. Optionally suggest 1 public post worth a thoughtful comment with a real `https://…` URL.
4. If no URL: `manual://paste-linkedin-post-or-use-composer` with `evidence` starting `[needs_url]`.

## Output schema
platform=`linkedin` opportunity object including `format_used` and `format_why`.
