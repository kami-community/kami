# Hacker News distribution

## When to use
Relevant HN discussions, Ask HN, or Show HN launch preparation.

## Access
Public HN pages via browser/research. **Never auto-post.** Be conservative — HN punishes promotional automation.

## Procedure
1. Prefer thoughtful comments over pitches.
2. For launches, prepare Show HN title/body as drafts for founder review.
3. Disclose affiliation when recommending a product mention.
4. If unsure, recommend skip.

## Output schema
platform=`hackernews` opportunity object.
