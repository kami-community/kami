# Hacker News distribution

## When to use
Relevant HN discussions, Ask HN, or Show HN launch preparation.

## Access
Public HN pages via browser/research. **Never auto-post.** Be conservative — HN punishes promotional automation.

## Procedure
1. Follow `viral_formats` for current HN-appropriate patterns; set `format_used` + `format_why`.
2. Prefer thoughtful comments over pitches.
3. For launches, prepare Show HN title/body as drafts for founder review.
4. Disclose affiliation when recommending a product mention.
5. Prefer real `https://news.ycombinator.com/item?id=…` URLs; else `manual://paste-hn-item-url` with `[needs_url]`.

## Output schema
platform=`hackernews` opportunity object including `format_used` and `format_why`.
